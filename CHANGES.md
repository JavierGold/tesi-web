# 6. NUEVA SECCIÓN — GESTIÓN DE PROYECTOS BAJO LINEAMIENTOS PMI

## Objetivo conceptual

Comunicar que TESI no solamente proporciona capacidad técnica.

La consultoría funciona como una Project Office y gestiona sus proyectos bajo
lineamientos y buenas prácticas del Project Management Institute (PMI).

La estructura debe comunicar:

- Project Office;
- Portafolio de proyectos;
- Project Managers;
- seguimiento y control;
- búsqueda sistemática de proyectos exitosos.

Un proyecto exitoso debe cumplir con:

- requerimientos;
- tiempo;
- costo;
- calidad.

TESI dispone para ello de:

- personal capacitado;
- herramientas;
- conocimiento;
- experiencia.

---

# 7. GRÁFICO PMI — CONCEPTO VISUAL

NO utilizar tarjetas tradicionales para representar este modelo.

Crear una composición gráfica:

**circular + radial + orbital + profundidad 3D sutil**

La composición debe parecer parte natural del diseño actual de TESI.

No debe parecer una escena de videojuego, dashboard futurista o demo de Three.js.

---

## 7.1 Núcleo

En el centro:

**PROYECTO EXITOSO**

Debe ser el elemento de mayor jerarquía.

Utilizar un núcleo circular con:

- profundidad ligera;
- borde fino;
- iluminación muy sutil;
- tipografía Manrope;
- colores pertenecientes a la identidad actual.

El núcleo debe permanecer perfectamente legible en todo momento.

---

## 7.2 Cuatro dimensiones del proyecto exitoso

Distribuir alrededor del núcleo:

### Requerimientos

Icono conceptual: checklist/documento.

### Tiempo

Icono conceptual: reloj.

### Costo

Icono conceptual: indicador financiero.

### Calidad

Icono conceptual: escudo/check.

Los cuatro elementos deben tener la misma jerarquía.

Deben estar conectados visualmente con el núcleo.

La conexión puede realizarse mediante:

- líneas finas;
- arcos;
- trayectorias;
- geometría radial.

No convertirlos en cuatro cards rectangulares convencionales.

---

## 7.3 Anillo exterior PMI

Crear alrededor de la composición un anillo que represente:

**LINEAMIENTOS PMI**

El concepto visual debe comunicar:

"PMI guía y envuelve la gestión del proyecto."

No utilizar el logotipo oficial de PMI.

No copiar recursos gráficos oficiales de PMI.

Utilizar únicamente el lenguaje visual propio de TESI.

---

## 7.4 Estructura organizacional

Integrar:

- Project Office;
- Portafolio de proyectos;
- Project Managers.

Estos elementos representan la estructura mediante la cual TESI organiza,
gestiona y da seguimiento a los proyectos.

## 7.5 Capacidades

- Personal capacitado;
- Herramientas;
- Conocimiento;
- Experiencia.

**¿Con qué cuenta TESI para lograr proyectos exitosos?**

### Paso 3 — Proyecto exitoso

### Paso 4 — Dimensiones del éxito

### Paso 5 — Capacidades

- Personal;
- Herramientas;
- Conocimiento;
- Experiencia.

# 9. ESTADO VIVO DEL GRÁFICO PMI

Una vez terminada la animación de entrada, NO dejar completamente congelado
el gráfico.

Mantener una sensación tecnológica mediante microanimaciones.

Permitido:

- rotación orbital extremadamente lenta del anillo PMI;
- movimiento de profundidad de pocos píxeles;
- respiración/pulsación mínima del núcleo;
- movimiento extremadamente sutil de conexiones;
- pequeños cambios de perspectiva;
- parallax interno mínimo.

El movimiento debe ser casi imperceptible.

El usuario debe poder leer perfectamente mientras ocurre.

NO utilizar:

- giros rápidos;
- rebotes;
- partículas;
- luces intensas;
- glow/neón;
- movimientos bruscos;
- objetos flotando exageradamente;
- efectos gaming.
